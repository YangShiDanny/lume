Lume

简单调用，最高效。

一门静态类型、编译到 C 的语言。你写直观的递归与循环，编译器负责把它们展开成查表、多线程和带向量化提示的 C 代码，剩下的交给 clang。

查看源码 快速开始
main.lume 
struct Point {
    x: float
    y: float

    fn len() -> float {
        return sqrt(x * x + y * y)
    }
}

@precompute(0, 30)   // 编译期算完，运行时查表
fn fib(n: int) -> int {
    if n < 2 { return n }
    return fib(n - 1) + fib(n - 2)
}

fn par_sum(a: [int], n: int) -> int {
    total: int = 0
    par for i in 0..n {
        total += a[i]   // 自动识别 reduction
    }
    return total
}

fn main() {
    p := Point(x: 3.0, y: 4.0)
    say("len = {p.len()}")      // 5.000000
    say("fib(30) = {fib(30)}")  // 832040
}

Why Lume

编译器替你做的优化

不用加任何开关。你写自然写法，Lume 负责证明、展开与并行，产物仍是普通 C。

@precompute

编译期求值

把纯函数的值域在编译期一次性算好、写进查表，运行时直接命中，不再重复计算。

par for

自动归约的多线程

识别 total += a[i] 为 reduction，每线程私有累加后合并，语义等同 OpenMP。

purity

纯函数证明

保守证明后为纯函数打上 __attribute__((const))，消除重复调用。

vectorize

向量化提示

对可向量化的循环发出 clang loop vectorize 提示，让 clang 生成 SIMD。

say / write

无锁异步输出

先写线程本地缓冲，不争 stdout 锁；满 64 KiB 异步提交给单一后台 writer。

target C

交给 clang

产物是标准 C，默认 -O3；--native / --lto / --fastmath 按需开启。

Under the hood

直观写法，硬核产物

递归、循环、结构体方法照常写；多线程 worker、纯函数标注、查表都由编译器生成。

Get started

三步跑起来

依赖 clang 在 PATH 里。clone 后用 cargo 运行即可。

$git clone https://github.com/YangShiDanny/lume
$cd lume
$cargo run -- run main.lume
$cargo run -- build main.lume
--native 本机指令 --lto 链接优化 --fastmath 放宽浮点 -O2 降优化 --unchecked 关边界检查

说明：Lume 把生成的 C 写在工作目录，文件名取源文件 stem，再调 clang 编译。Windows 目前走 WSL（见仓库 run.bat）。
